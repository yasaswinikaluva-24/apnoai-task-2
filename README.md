
# ✨ ApnoAI Internship Task 2 – React Profile Card

A modern, interactive and responsive developer profile card built using React. This project was developed as part of the ApnoAI Web Development Internship.

## 🌟 Project Overview

This project showcases a personalized developer profile with a premium visual design, interactive features and reusable React components.

The profile card highlights personal information, technical skills and social links in a clean and engaging interface.

## 🚀 Features

- **Reusable React Component:** ProfileCard component built using props.
- **Personalized Profile:** Displays name, role, introduction and technical skills.
- **Dark and Light Mode:** Interactive theme switching using React useState.
- **Like Counter:** Interactive Like and Unlike functionality.
- **Connect Button:** Direct link to LinkedIn profile.
- **Social Links:** GitHub and LinkedIn profile links.
- **Responsive Design:** Adapts to different screen sizes.
- **Custom Avatar:** Uses a fictional illustrated developer avatar.
- **Modern UI:** Gradient backgrounds, visual effects and styled components.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React 18
- React Hooks (useState)
- Tailwind CSS
- Babel
