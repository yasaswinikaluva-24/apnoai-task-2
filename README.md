## 🌟 Project Overview

This project is a personalized developer profile card designed to showcase professional identity, technical skills, personal introduction, and social media profiles through an attractive and interactive user interface.

It demonstrates the use of reusable React components, props, and React Hooks while combining modern styling with interactive features.

## ✨ Features

- **Reusable React Component:** A reusable `ProfileCard` component built using React props.
- **Personalized Profile:** Displays developer name, professional role, introduction, and technical skills.
- **Dark and Light Mode:** Switch between themes using React `useState`.
- **Interactive Like Counter:** Like and Unlike functionality with a dynamic counter.
- **Connect Button:** Direct access to the developer's LinkedIn profile.
- **Social Media Links:** Quick access to GitHub and LinkedIn.
- **Responsive Design:** Adapts to different screen sizes.
- **Custom Avatar:** Uses a fictional illustrated developer avatar.
- **Modern UI:** Gradient backgrounds, glowing effects, rounded cards, and smooth transitions.
- **Avatar Fallback:** Displays initials if the avatar image cannot load.

## ⚙️ How to Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/yasaswinikaluva-24/apnoai-task-2.git
```

**2. Open the project folder**

```bash
cd apnoai-task-2
```

**3. Run the project**

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

**Note:** This project uses React, Tailwind CSS, and Babel through CDN links. An npm installation or build process is not required.

## 🧠 React Concepts Implemented

### 1. Functional Components

Created a reusable `ProfileCard` functional component to organize and display profile information.

### 2. Props

Used props to pass dynamic profile information such as:

- Name
- Role
- Bio
- Skills
- Avatar
- GitHub link
- LinkedIn link

### 3. React useState Hook

Implemented React `useState` to manage:

- Dark and light theme switching.
- Like and Unlike functionality.
- Dynamic Like counter.
- Avatar loading fallback.
